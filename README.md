# Next.js Project

## Getting Started

### Step 1: Install Dependencies

Run the following command to install the required dependencies:

npm install  
yarn install

### Step 2: Start the Development Server

To start the application in development mode, use:

yarn dev  
npm run dev

### Step 3: Build for Production

To create an optimized production build, run:

yarn build  
npm run build

### Step 4: Watch and Compile SASS Files

To watch and compile SASS files, use the following command:

sass --watch public/sass/style.sass:public/assets/css/style.css

This will automatically compile your SASS files into CSS whenever changes are made.
